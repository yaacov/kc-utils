# firstboot plugins (Windows)

`Contributor` interface — generate PowerShell or batch firstboot scripts for Windows guests.

| Key | Package | Contributor |
|-----|---------|-------------|
| `diskonliner` | diskonliner/ | Bring offline disks online at first boot |
| `multipleips` | multipleips/ | Configure additional IP addresses |
| `pnputil` | pnputil/ | Install staged VirtIO drivers via pnputil |
| `qemuga` | qemuga/ | Install QEMU guest agent |
| `routecleanup` | routecleanup/ | Clean stale network routes |
| `signal` | signal/ | Signal conversion completion to orchestrator |
| `staticipfb` | staticipfb/ | Apply static IP configuration |
| `vmwarecleanup` | vmwarecleanup/ | Remove VMware Tools leftovers |
