# distro plugins

`DistroHandler` interface — classify OS family, package format, and package manager.

| Key | Package | Distros |
|-----|---------|---------|
| `rhel` | rhel/ | RHEL, CentOS, Rocky, Alma, Oracle Linux, Fedora, Amazon Linux (`amzn`) |
| `debian` | debian/ | Debian, Ubuntu |
| `suse` | suse/ | SLES, openSUSE |
